
# Øygarden Trygghet

## Om prosjektet

Øygarden Trygghet er et skoleprosjekt laget som en del av JavaScript Advanced Oppgave 2 hos Jobloop Kodehode.

Applikasjonen er et personlig dashboard for å registrere og organisere sikkerhetsobservasjoner i Øygarden.

Dette er ikke en offisiell kommunal tjeneste. Observasjonene er lokale og sendes ikke til kommunen.

## Funksjonalitet

- Registrere nye sikkerhetsobservasjoner
- Lagre data i localStorage
- Vise registrerte observasjoner
- Redigere eksisterende observasjoner
- Slette enkeltobservasjoner
- Slette alle observasjoner
- Filtrere etter sted og kategori
- Sortere etter dato eller tittel
- Vise statistikk over registrerte observasjoner
- Avbryte redigering

## JavaScript-metoder

Prosjektet bruker:

- map()
- filter()
- sort()
- reduce()
- Destructuring
- Event listeners
- JSON.parse() og JSON.stringify()

## Teknologier

- HTML5
- CSS3
- JavaScript
- localStorage
- GitHub Pages

## Personvern

Alle observasjoner lagres lokalt i brukerens nettleser med localStorage. Dataene deles ikke automatisk med andre brukere.
